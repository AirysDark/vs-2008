# Visual Studio 2008 Windows 7 VirtualBox Package

Converted from the original Chef cookbook layout into an offline VM preparation package.

Usage:
1. Install Windows 7 SP1 in VirtualBox.
2. Install VirtualBox Guest Additions.
3. Copy this folder into the VM.
4. Place required installers in the installers folder.
5. Run install.bat as Administrator.

Original Chef files are kept for reference.
